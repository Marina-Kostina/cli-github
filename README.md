# CLI-GitHub

CLI-инструмент для получения информации о репозитории GitHub.

Программа отправляет HTTP-запрос к GitHub API, получает JSON-ответ и выводит ключевую информацию.

## Описание:

Инструмент принимает название репозитория в формате `владелец/репозиторий`, отправляет запрос к GitHub и выводит:
- Имя репозитория
- Описание
- Количество звёзд
- Количество форков
- Дату создания

## Требования:

- Go 1.16 или выше
- Пакеты стандартной библиотеки(net/http, encoding/json, fmt, io, os, strings)

## Установка:

1) Сохраните файл как `homework1.go`
2) Откройте терминал в папке с файлом
3) Запустите программу:

## Запуск:

```bash
go run homework1.go владелец/репозиторий
```
